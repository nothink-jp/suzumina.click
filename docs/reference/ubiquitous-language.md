# ユビキタス言語

ドメイン用語の意味と、名前だけでは分からない**由来・判断**の記録。必要になった時だけ参照する（能動ルールは [CLAUDE.md](../../CLAUDE.md)）。
フィールド名・型・上限値は書かない（正本は `packages/shared-types` と各実装。在処は [domain-model.md](domain-model.md) / [database-schema.md](database-schema.md)）。

## サイトの位置付け

| 用語 | 意味 |
|---|---|
| 涼花みなせ（すずか みなせ） | 本サイトの中心となる声優。サイト名の由来 |
| ファンサイト | suzumina.click の位置付け。広告を掲載しない非営利運営（公開記述は privacy ページ） |
| すずみなふぁみりー | 涼花みなせの Discord サーバー。所属は認可には使わず、音声ボタン作成の日次上限にのみ効く（[rate-limit-utils.ts](../../apps/web/src/lib/rate-limit-utils.ts)） |

ユーザーは「認証済みか」と「有効（`isActive`）か」だけで区別する。ロール（admin / moderator）と管理画面は SPR-164 で撤去済み。

## 音声ボタン

| 用語 | 意味 |
|---|---|
| 音声ボタン（Audio Button） | YouTube 動画の時間範囲を**参照**し、ワンクリックで再生する単位。音声ファイルは保存しない（再生は YouTube 埋め込み） |
| ソース動画 | 音声ボタンが参照する YouTube 動画 |
| 下書き（Button Draft） | 配信視聴中に「ここ！」とマークした生の捕捉信号。仕上げて音声ボタンにする（SPR-146） |
| お気に入り / 高評価 / 低評価 | ユーザー個人が音声ボタンに付ける印 |

## 動画

| 用語 | 意味 |
|---|---|
| 配信アーカイブ | 配信が終了し、長さが **15 分閾値**を超える動画。**音声ボタンを作れるのはこれだけ** |
| プレミア公開 | 配信と同じ形で記録されるが 15 分閾値以下のもの。長さで配信アーカイブと区別する |
| 通常動画 | 配信情報を持たないアップロード動画 |
| 配信中・配信予定 | 未終了の配信 |
| 15 分閾値 | プレミア公開と配信アーカイブを分ける長さの基準。動画種別の判定と音声ボタン作成可否が同じ基準を共有する（判定は transformer / Cloud Function / 作成時検証に分散しているので、変えるなら全箇所を揃える） |
| プレイリストタグ | YouTube プレイリスト名から自動生成されるタグ |
| YouTube カテゴリ | 投稿者が選んだカテゴリの日本語表示 |

「3 層タグ」はプレイリスト / ユーザー / カテゴリの 3 層だった名残。**ユーザータグは編集 UI・Server Action とも撤去済み**で、
値を書く経路は残っていない（SPR-273 / SPR-276。フィールドは移行判断のため残置）。

## DLsite 作品・サークル・クリエイター

| 用語 | 意味 |
|---|---|
| 作品（Work） | DLsite で販売される涼花みなせ参加作品。Firestore コレクションは **`works`** |
| 作品 ID | DLsite の商品 ID（`RJ` 始まり） |
| サークル（Circle） | 作品を制作・販売する同人サークル（ID は `RG` 始まり） |
| クリエイター（Creator） | 作品制作に関わった人物。声優・シナリオ・イラスト・音楽・その他の**役割**を持ち、一人が複数役割を持ちうる |
| クリエイター ⇔ 作品の関連 | クリエイターごとのサブコレクションに持つ非正規化データ（ルートコレクション `creatorWorkMappings` は存在しない） |
| 親作品 / 子作品 | 翻訳版・エディション展開の元と派生 |
| 定価 / セール価格 | キャンペーン適用前 / 適用後の価格 |
| 価格履歴 | 作品価格の日別記録（多通貨） |

- **`works` への改名（2025-07）**: 旧称 `dlsiteWorks`。`videos` / `users` / `circles` と命名規則を揃えるために改名した。
  旧称や別名で参照しない。
- **二重割引**: DLsite API の価格は既に割引適用済みで、割引率は表示用の付帯情報。これを価格に再適用すると二重に割り引かれる
  （価格履歴で実際に発生し修正済み。経緯は [work-mapper.ts](../../apps/functions/src/services/mappers/work-mapper.ts) の価格変換の JSDoc）。
- **データ取得**: 作品 ID の一覧は DLsite から収集し、各作品の詳細は Individual Info API で取得する。
- **非正規化**: サークルの作品一覧・クリエイター関連・統計値は読み取り効率のための複製。整合は週次 cron が事後修復する（CLAUDE.md §0 軸1）。

## 作品評価

| 用語 | 意味 |
|---|---|
| 作品評価 | ユーザーが作品に付ける評価。**10 選 / 星 / NG の 3 種は排他**（1 ユーザー × 1 作品に 1 つだけ） |
| 10 選 | ユーザーが特別な作品を順位付けするランキング。順位は重複しない |
| 星評価 | 3 段階の通常評価 |
| NG | 苦手な作品の印 |
| スタック型挿入 | 10 選の指定順位に挿入すると、それ以下が 1 つずつ下がる |
| 押し出し | 満杯の 10 選に挿入して溢れた作品は、評価を失わず**最高段階の星評価**に変わる |

評価と 10 選は同一トランザクションで更新する（実装は `apps/web/src/app/works/[workId]/evaluation-actions.ts`）。
